# Результаты нагрузочного тестирования

Окружение: **4 vCPU, 6 GB RAM**, файл 1 MB, `CACHE__READ_BUF_SIZE=131072` (128 KB).

## Origin vs Cache — сравнение

### Hot Key (один файл 1 MB, target 500 RPS, 50 VUs, 60s)

| Метрика | Origin Baseline | Cache Hot Key | Разница |
|---------|-----------------|---------------|---------|
| RPS | 260.2 | 379.9 | **+46%** |
| Всего запросов | 15 682 | 22 866 | +45.8% |
| avg задержка | 269.0 ms | 172.0 ms | **-36%** |
| med задержка | 248.9 ms | 153.2 ms | -38% |
| p95 задержка | 494.4 ms | 354.0 ms | **-28%** |
| p99 задержка | 656.3 ms | 520.0 ms | **-21%** |
| Hit ratio | — | 100.0% | |
| Coalescing | — | effective (1 MISS) | |

Edge-cache обгоняет origin по всем метрикам на hot key сценарии после оптимизации буфера чтения.

### Точка деградации (ramping 50 -> 1950 RPS, 30s на ступень)

| Метрика | Origin Degrade | Cache Degrade | Разница |
|---------|----------------|---------------|---------|
| Точка деградации | **~300 RPS** | **~500 RPS** | **+67%** |
| Всего запросов | 16 136 | 35 420 | **+119%** |
| RPS (средний) | 144.2 | 210.8 | **+46%** |
| avg задержка | 108.0 ms | 133.9 ms | +24% |
| med задержка | 8.2 ms | 4.3 ms | **-48%** |
| p95 задержка | 604.3 ms | 616.7 ms | +2% |
| p99 задержка | 1005.4 ms | 1162.7 ms | +16% |

Cache обработал в **2.2x больше запросов** до срабатывания abort-порогов. Медианная задержка на низких ступенях в 2 раза ниже (4.3 ms vs 8.2 ms). Повышенный p99 объясняется тем, что cache дожил до более высоких ступеней RPS, где задержки растут нелинейно.

## Выводы

1. **Edge-cache быстрее origin на +46% RPS** для горячего файла 1 MB.

2. **Coalescing работает корректно** — при 22 866 запросах к одному файлу origin был вызван ровно 1 раз.

3. **Cache устойчивее при росте нагрузки** — обработал 2.2x больше запросов до точки деградации.

4. **Warm-кэш с медианой 0.6 ms** — на мелких файлах edge-cache работает практически мгновенно.
