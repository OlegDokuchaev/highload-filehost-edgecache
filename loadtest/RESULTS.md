# Результаты нагрузочного тестирования

Окружение: **4 vCPU, 6 GB RAM**, файл 1 MB.

## Origin vs Cache — сравнение

### Hot Key (один файл 1 MB, target 500 RPS, 50 VUs, 60s)

| Метрика | Origin Baseline | Cache Hot Key | Разница |
|---------|-----------------|---------------|---------|
| RPS | 260.2 | 403.1 | **+55%** |
| Всего запросов | 15 682 | 24 267 | +54.7% |
| avg задержка | 269.0 ms | 158.4 ms | **-41%** |
| med задержка | 248.9 ms | 143.9 ms | -42% |
| p95 задержка | 494.4 ms | 324.9 ms | **-34%** |
| p99 задержка | 656.3 ms | 450.2 ms | **-31%** |
| Hit ratio | — | 100.0% | |
| Coalescing | — | effective (1 MISS) | |

Edge-cache обгоняет origin по всем метрикам на hot key сценарии после внедрения mmap.

### Точка деградации (ramping 50 -> 1950 RPS, 30s на ступень)

| Метрика | Origin Degrade | Cache Degrade | Разница |
|---------|----------------|---------------|---------|
| Точка деградации | **~300 RPS** | **~750 RPS** | **+150%** |
| Всего запросов | 16 136 | 44 613 | **+176%** |
| RPS (средний) | 144.2 | 254.3 | **+76%** |
| avg задержка | 108.0 ms | 150.9 ms | +40% |
| med задержка | 8.2 ms | 6.4 ms | **-22%** |
| p95 задержка | 604.3 ms | 679.5 ms | +12% |
| p99 задержка | 1005.4 ms | 1113.8 ms | +11% |

Cache обработал в **2.8x больше запросов** до срабатывания abort-порогов. Медианная задержка ниже (6.4 ms vs 8.2 ms). Повышенные avg/p95/p99 объясняются тем, что cache дожил до значительно более высоких ступеней RPS, где задержки растут нелинейно.

## Выводы

1. **Edge-cache быстрее origin на +55% RPS** для горячего файла 1 MB (mmap + sync I/O).

2. **Coalescing работает корректно** — при 24 267 запросах к одному файлу origin был вызван ровно 1 раз.

3. **Cache устойчивее при росте нагрузки** — обработал 2.8x больше запросов до точки деградации (~750 RPS vs ~300 RPS у origin).

4. **Warm-кэш с медианой 0.7 ms** — на мелких файлах edge-cache работает практически мгновенно.
